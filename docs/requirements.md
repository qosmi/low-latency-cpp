# Initial Software Requirements

These are engineering requirements for the portfolio simulation, not regulatory requirements for a medical device.

| ID | Requirement |
|---|---|
| REQ-001 | The system shall generate a configurable number of detector events. |
| REQ-002 | The acquisition queue shall have a fixed capacity. |
| REQ-003 | Queue overflow shall be observable through a dropped-event counter. |
| REQ-004 | The processing stage shall consume events concurrently with acquisition. |
| REQ-005 | The application shall report processed and dropped events. |
| REQ-006 | Performance claims shall be supported by measurements. |
| REQ-007 | The project shall provide automated tests before optimization work is accepted. |
